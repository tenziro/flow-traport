# 시스템 UX 라이팅 가이드

**적용 대상**: 사용자에게 노출되는 모든 문구 — 화면 텍스트, 버튼 라벨, 에러 메시지, 다이얼로그, 안내 문구, 빈 상태 문구, 코드 주석, 변수명, 개발 문서, 로그 등 전체 문장
**적용 안 함**: AGENTS.md, CLAUDE.md

---

## 빠른 판정표

문구를 쓰거나 고칠 때 위에서부터 확인해요. 각 규칙에는 예외가 있고, 예외는 해당 규칙 안에 함께 있어요.

| #   | 규칙                                      | X                | O                         |
| --- | ----------------------------------------- | ---------------- | ------------------------- |
| 1   | [해요체](#1-해요체)                       | 확인하십시오     | 확인해요                  |
| 2   | [능동형](#2-능동적-말하기)                | 처리가 됐어요    | 처리했어요                |
| 3   | [긍정형](#3-긍정적-말하기)                | 가입할 수 없어요 | 허락하면 가입할 수 있어요 |
| 4   | [캐주얼한 경어](#4-캐주얼한-경어)         | 해지하시겠어요?  | 해지할까요?               |
| 5   | [명사+명사 금지](#5-명사--명사-쓰지-않기) | 잔액 부족으로    | 잔액이 부족해서           |

**항상 적용 (예외 없음)**

- `되어요` → `돼요` (모바일 화면 공간을 고려해 통일)
- 다이얼로그 왼쪽 버튼은 `닫기` — `취소`는 작업이 취소된다고 오해할 수 있어서 쓰지 않아요

## 1. 해요체

**규칙**: 상황과 맥락을 불문하고 모든 문구에 해요체를 적용해요. 일관성 있는 사용자 경험을 만들기 위해서예요.

**예외**: 없어요.

---

## 2. 능동적 말하기

**규칙**: 최대한 능동형 문장을 써요. `~었` 을 빼요.

| X      | O      |
| ------ | ------ |
| 됐어요 | 했어요 |

### 예외 — 수동형을 쓰는 게 나은 경우

수동형이 더 명확하고 간결할 때가 있어요. 아래 세 가지 상황에서만 써요.

**a. 서비스 종료 · 기간 만료**

- 주어(종료 서비스, 기간 등)를 강조할 수 있어요.
- '종료'와 '만료'의 뉘앙스를 정확히 전달할 수 있어요.
- 단, 주기적으로 종료가 반복되는 제품에는 `종료돼요`를 쓰지 않아요 → `끝나요`

**b. 사용자에게 미치는 영향을 알려줄 때** (주요 동사: 연체, 해지, 적용)

- 인과 관계를 명확하게 설명해요. '사용자의 행동에 따라오는 결과'라는 점을 알려줄 수 있어요.

**c. 사용자 안심**

- '정보 수집 안내' 같은 민감한 상황에서 사용자를 안심하게 할 수 있어요.

---

## 3. 긍정적 말하기

**규칙**: 부정적 커뮤니케이션을 줄이고 긍정형 문장을 써요. `안 돼요`, `없어요` 대신 `~하면 할 수 있어요`.

### 없어요 → 있어요

| X                                         | O                                  |
| ----------------------------------------- | ---------------------------------- |
| 보호자가 허락하기 전에는 가입할 수 없어요 | 보호자가 허락해야 가입할 수 있어요 |

### 에러 메시지

'무엇이 안 되는지'가 아니라 '무엇을 하면 되는지'를 알려줘요.

| X                                                       | O                                       |
| ------------------------------------------------------- | --------------------------------------- |
| 지금 버전에서는 쓸 수 없어요                            | 앱을 업데이트해주세요                   |
| 생체 인증을 쓰려면 앱을 최신 버전으로 업데이트 해주세요 | 생체 인증을 쓰려면 최신 버전이 필요해요 |

> 다이얼로그 왼쪽 버튼은 **닫기**로 문구를 통일해요. **취소**는 사용자가 하고 있는 작업이 취소된다고 오해할 수 있어 쓰지 않아요.

### 혜택을 받을 수 없을 때

| X                                    | O                                           |
| ------------------------------------ | ------------------------------------------- |
| 모임지원금 없이 모임통장을 만들까요? | 약관에 동의하면 모임지원금을 받을 수 있어요 |

### 혜택 대상 안내

서비스는 쓸 수 있지만 특정 혜택만 못 받을 때는 긍정형으로 써요. 사용자는 문구를 훑어 읽기 때문에 제품 전체를 쓸 수 없다고 오해하기 쉬워요.

| X                               | O                               |
| ------------------------------- | ------------------------------- |
| 계좌 개설 혜택은 받을 수 없어요 | 4.5% 금리 혜택만 받을 수 있어요 |

### 예외 — 부정형을 쓰는 게 나은 경우

**a. 서비스를 정책상 쓸 수 없을 때**

- 부정형이라야 사용자에게 상황을 명확하게 인지시킬 수 있어요. 쓸 수 없는 이유를 함께 안내해주세요.

**b. 일부 기능만 쓸 수 없을 때**

- 어떤 기능을 쓸 수 없는지, 사용자 선택의 결과가 무엇인지 명확하게 알려줄 수 있어요.
- ※ 바로 위 '혜택 대상 안내'와 헷갈리지 마세요. **혜택**을 못 받는 건 긍정형, **기능**을 못 쓰는 건 부정형이에요.

**c. 사용자 안심**

- '정보 수집 안내' 같은 민감한 상황에서 사용자를 안심하게 할 수 있어요.

## 4. 캐주얼한 경어

**규칙**: `~시겠어요?`, `~시나요?`, `~께` 같은 과도한 경어를 쓰지 않아요. 캐주얼하고 친근한 말투를 써요.

### 동사에서 '~시' 빼기

| X                                         | O                              |
| ----------------------------------------- | ------------------------------ |
| 카드를 해지하시겠어요?                    | 카드를 해지할까요?             |
| 오늘 로그인하시는 분에게 5,000원을 드려요 | 오늘 로그인하면 5,000원 드려요 |

### '계시다' → '있다'

| X                                 | O                         |
| --------------------------------- | ------------------------- |
| 자동차를 가지고 계시나요?         | 자동차가 있나요?          |
| 매달 보험료 얼마씩 내고 계시나요? | 매달 보험료는 얼마인가요? |

### '여쭈다' → '확인하다, 묻다'

| X                                          | O                                          |
| ------------------------------------------ | ------------------------------------------ |
| 안전한 개통을 위해 몇 가지 다시 여쭤볼게요 | 안전한 개통을 위해 몇 가지 다시 확인할게요 |

### '께' → '에게'

| X                                         | O                                           |
| ----------------------------------------- | ------------------------------------------- |
| 슈퍼뱅크카드가 김슈퍼님께 날아가고 있어요 | 슈퍼뱅크카드가 김슈퍼님에게 날아가고 있어요 |

### 경어를 뺐더니 어색할 때

기계적으로 '~시'를 빼면 문장이 어색할 수 있어요. **파악하고 싶은 정보를 주어로 삼아 문장을 새로 써보세요.**

| X                             | O                        |
| ----------------------------- | ------------------------ |
| 어떤 목적으로 대출받으시나요? | 대출 목적이 무엇인가요?  |
| 어떤 이유로 신고하시나요?     | 신고 이유를 선택해주세요 |

### 예외 — 경어를 써도 되는 경우

`시나요?`, `셨나요?` 의문형 어미를 제한적으로 쓸 수 있어요.

**a. 사용자의 맥락을 활용해서 질문할 때** — 사용자의 당황스러움을 줄일 수 있어요.
**b. 사용자의 상황을 추정할 때** — 시스템에 명확한 정보가 없어서 사용자가 직접 판단해야 할 때 정중하게 물어봐요.
**c. 사용자의 선의가 필요할 때** — 설문조사처럼 사용자의 선의를 기대해야 할 때 정중하게 물어봐요.

## 5. '{명사} + {명사}' 쓰지 않기

**규칙**: 한자어 명사를 나열하지 말고, 풀어서 동사 형태로 써요.

### 한자어 풀어쓰기

| X                               | O                             |
| ------------------------------- | ----------------------------- |
| 이자 환불을 받았어요            | 이자를 돌려받았어요           |
| 내일 카드값이 결제될 예정이에요 | 내일은 카드값 나가는 날이에요 |

### 풀어쓰기 어려울 때

`{명사}가 {명사}해서` 형태로만 바꿔도 더 캐주얼해져요.

| X                               | O                                 |
| ------------------------------- | --------------------------------- |
| 잔액 부족으로 구매하지 못했어요 | 잔액이 부족해서 구매하지 못했어요 |

**예외**: 없어요.
